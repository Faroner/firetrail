# FireTrail — Порождение Тьмы

Minecraft 1.20.1 / Forge 47.4.0 / Iron's Spells 'n Spellbooks 3.16.3 / GeckoLib 4.8.4.

## Новое заклинание: «Порождение Тьмы»

После применения заклинания игрок сразу получает демоническую форму: обычная текстура игрока заменяется на чёрную с ярко-белыми глазами. Вокруг игрока появляются тёмные частицы. Форма длится 30 секунд, после чего автоматически возвращается обычный скин.

ID заклинания: `firetrail:dark_spawn`

Для визуальной замены текстуры используется client-side Mixin в `PlayerRenderer`, а состояние формы синхронизируется через Forge SimpleChannel, поэтому в мультиплеере форма может отображаться другим игрокам.

# Сборка через GitHub Actions

1. Загрузите содержимое проекта в репозиторий.
2. Сделайте Commit changes.
3. Откройте Actions → Build Fire Trail.
4. После успешной сборки скачайте artifact `firetrail-1.0.0`.

Для игры требуется Minecraft 1.20.1, Forge 47.4.0, Iron's Spells 'n Spellbooks 3.16.3 и GeckoLib 4.8.4.
